# IdeaDock

A native macOS idea capture app for saving a thought quickly and finding it later. Your library stays on your Mac.

- Capture text, links, code, images, files, and folders without organizing first.
- Browse an automatic day-by-day history with original capture times.
- Press **⌘K** to find a note or reopen a recent capture.
- Drag floating notes around the desktop and dock them to any screen edge or corner.

## Downloads

- [Apple silicon macOS app](./IdeaDock-macOS.zip)
- [Swift package source](./IdeaDock-Source.zip)

Unzip the source archive, then run `./scripts/build.sh` to build and `./scripts/test.sh` to run the included self-tests. Requires macOS and Apple Swift command-line tools. The app is locally signed for personal use and is not notarized for public distribution.

See `docs/Verification.md` inside the source archive for the tested flows and remaining manual checks.
