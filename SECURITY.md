# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

## Reporting a Vulnerability

IdeaDock processes user input locally on macOS without any remote servers or cloud analytics.

If you discover a security vulnerability or sandbox escape risk, please report it privately by opening a security advisory on GitHub or emailing the maintainer directly at `hkimeko@gmail.com`.
