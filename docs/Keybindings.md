# Keybindings Reference

IdeaDock provides seamless keyboard shortcuts for rapid navigation and capture.

## Global Shortcuts

| Shortcut | Description |
| :--- | :--- |
| `⌥ Space` | Open Quick Capture HUD from any app |
| `⇧ ⌘ V` | Explicitly capture current system clipboard |

## Capture HUD Shortcuts

| Shortcut | Description |
| :--- | :--- |
| `⌘ Return` / `Return` | Save capture into Inbox |
| `⇧ Return` | Insert newline in capture draft |
| `Escape` | Dismiss capture HUD without saving |
| `⌘ 1..9` | Assign category directly |

## Library & Search Shortcuts

| Shortcut | Description |
| :--- | :--- |
| `⌘ K` | Open Command Palette search modal |
| `⌘ F` | Focus library search bar |
| `↑` / `↓` | Navigate note results list |
| `Return` | Open selected note in editor |
| `⌘ Backspace` | Archive selected note |
| `⌘ D` | Dock currently focused floating note |
| `⌘ ,` | Open Application Settings |
