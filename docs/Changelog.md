# Changelog

All notable changes to IdeaDock are documented in this file.

## [1.2.0] - 2026-10-03
### Added
- Eight-directional screen edge docking for desktop floating notes.
- Command Palette (⌘K) with fuzzy note lookup and quick actions.
- Automatic hashtag extraction and syntax recognition.
- Portable JSON backup with embedded images and Markdown export.
- Self-contained headless test runner (`--self-test`).

### Fixed
- Fixed coordinate handling for multi-monitor setups with negative offsets.
- Resolved race conditions in asynchronous item provider loading.
- Improved memory management in thumbnail image caching.

## [1.1.0] - 2026-09-20
### Added
- SwiftData persistence engine replacing custom JSON flat-files.
- Drag-and-drop ingestion of images, PDFs, and folders.
- Dark Aqua and Light Aqua adaptive color palette.

## [1.0.0] - 2026-09-01
### Added
- Initial release of IdeaDock native macOS capture client.
- Global ⌥Space capture overlay.

## [1.2.1] - 2026-10-04
### Enhanced
- Refined spring dynamics and snapping physics for edge docks.
- Added host domain parser for captured URLs.
- Enhanced thumbnail cache size boundaries and formatting utilities.
- Finalized repository documentation and CI/CD pipelines.
