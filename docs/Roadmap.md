# Product Roadmap

## Completed (v1.2.0)
- [x] Lightweight quick capture HUD with multiline text support
- [x] Eight-corner edge docking with spring animations
- [x] SwiftData persistent local storage
- [x] Automatic tag, link, and code type extraction
- [x] Command Palette (⌘K) rapid search
- [x] Zero-dependency JSON and Markdown export/import
- [x] Built-in automated self-test verification suite

## Upcoming Milestones (v1.3.0 - v2.0.0)
- [ ] **iCloud Drive Encrypted Sync**: Optional peer-to-peer or CloudKit sync across Macs.
- [ ] **Spotlight Indexing**: Native `CoreSpotlight` integration for searching IdeaDock notes from macOS Spotlight.
- [ ] **Raycast / Alfred Extension**: Deep link schema (`ideadock://capture?text=...`) for launcher workflows.
- [ ] **Menu Bar Quick Pad**: Embedded mini-scratchpad popover right from the macOS status bar.
- [ ] **Voice Memo Audio Transcription**: On-device Apple Speech framework transcription for quick audio thoughts.
